# Manya Jain — Portfolio

A personal portfolio site for Manya Jain: AI builder, brand-grower and professional over-thinker. It covers her story, projects, work experience, certificates, education, hobbies, and a contact section.

## Technologies

- One self-contained HTML file (`public/index.html`) with inline CSS and vanilla JavaScript
- Google Fonts (Bricolage Grotesque, Newsreader)
- Hosted on Netlify as a static site, with no build step

## Running locally

Open `public/index.html` in a browser, or serve the folder:

```bash
npx serve public
# or
netlify dev
```
