## ✨ About this website

The whole site is **one HTML file**: no React, no frameworks and no build step. Just hand-written HTML, CSS and JavaScript.

### Things to look for on the live site
- 🔍 **A secret on the home page.** Move your pointer over my name (or drag across it on a phone) and see what's underneath.
- 🌗 **Light and dark themes** that follow your device settings automatically.
- 🎬 **Page wipe transitions** between sections, powered by a tiny custom router.
- 🃏 **Cards that tilt** toward your cursor.
- 🔢 **Numbers that count up** as they appear.
- 🧘 **Calm mode.** One button turns off all the motion, and it's on automatically if your device asks for reduced motion.
- ✉️ **A friendly contact form** that opens your email app with the message already written, plus a one-click "copy my email" button.

### How it's built

| Piece | How it works |
|---|---|
| **Content** | All the text lives in plain JavaScript data objects (`PROJ`, `EXP`, `CERT`, `STORY` and more), so updating the site means editing data, not markup |
| **Routing** | A small hash router (`#home`, `#story`, `#projects`, ...) swaps sections with an animated wipe |
| **Theming** | CSS custom properties on `:root`, switched by `prefers-color-scheme` |
| **Illustrations** | Each project's artwork is a hand-coded SVG generated in JavaScript |
| **Accessibility** | Respects reduced-motion settings and labels its illustrations for screen readers |
| **Fonts** | Bricolage Grotesque and Newsreader, from Google Fonts |
| **Hosting** | Netlify, deployed automatically on every push to `main` |

### What's in the repo

```
.
├── public/
│   └── index.html    ← the entire site: markup, styles and scripts
├── netlify.toml      ← tells Netlify to publish the public/ folder
└── README.md         ← you are here
```
